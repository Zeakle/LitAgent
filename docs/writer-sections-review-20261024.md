# 同一 Worker 内的章节生成修复

本轮针对真实的章节嵌套错误修改执行粒度，未增加 Agent 或第二套正文格式。`grounded-writer-execution-v6` 已完成离线验收，尚未执行新的真实三域验收；Phase 14.5 保持 `in_progress`。

## 依据及实现

[第四组固定验收](../benchmarks/survey/results/frozen-writer-three-domain-20261024-004/README.md)在首个 Pro 请求失败，只有 2,380 输出 tokens，未触及 20,000 输出上限，但 taxonomy 已嵌入 introduction 容器。增加 timeout 或补末尾括号不能修复这份响应。

现有 Synthesis Worker 串行生成固定五章。每章响应 schema 从原完整 `grounded-writer-v1` schema 的已有字段派生，第一章额外包含原 title。没有新增模型输出字段，也没有让模型维护章节位置、事实类别或最终引用。宿主按原顺序无损组装，再执行原完整 schema、正文检查、摘要依赖、Reviewer 和 Evaluation。

每次请求均保留完整来源、全局卡目录、研究问题和覆盖要求。已生成章节只是不可信写作上下文，不能替代原始证据。未知引用的候选完整保留，只有既有引用 enum 错误可进入原完整正文修复路径；无效章节不成为后续科学前提。JSON、类型、额外字段、空章节或嵌入布局错误立即终止，不发送依赖的后续章或摘要。

每章使用唯一的 `body:<section>` 请求身份，发送前持久化，保存原始响应、SHA、usage 和终止状态。已完成前缀或取消／未知请求均不自动重发；拒绝重启时不覆盖原始失败 journal。新执行版本进入运行身份，旧执行 checkpoint 不跨版本恢复。

## 预算与科学边界

五次初稿请求均计入原 500,000 tokens／64 请求。20,000 最大输出预留、阶段额度、10% 上下文余量、超时、零重试及两次共享修复保持。没有通过降低输出预留、裁剪原文或借用 Evaluation 额度来发送请求。

正文全部完成后才生成摘要和结论；章节局部合法不代表科学支持。128 条模型断言容量、支持率 1.0、核心覆盖、全局一致性与最终版本绑定均不变。Judge/Jev 继续独立可选，本轮关闭。

## 验收证据

- 最终默认 `pytest -v`：**4274 passed、25 deselected、8 warnings**；修改 Python 的 Black/isort 和 diff 检查通过。
- 新增章节 schema 投影、完整来源／上下文、无损组装、错误章节停止、未知引用完整候选及共享修复、取消前缀不重发测试；现有实际 Synthesis→Reviewer→唯一报告出口→Evaluation 正反例继续通过。
- 实际 SDK 编码／路由测试证明五章及摘要均使用 Pro、Reviewer 使用 Lite，七个请求各自计费、零重试。
- 真实 SDK 离线预算反例设置 60k 测试总额及 synthesis 上下文：写作阶段上限 36k，首请求预留 29,901、结算 20k 后，下一请求在传输前被预算拒绝；不会借用后续额度。
- 使用旧 few-shot 003 的完整、未核验正文作离线回放上下文，五章实际请求预留分别为 **56,858／58,732／60,825／65,946／68,979**；每次完整来源 SHA 相同，输出预留均为 20k。此为请求重建，不是新模型结果。
- ViT、NeRF 首章完整请求预留分别为 **63,115／63,241**；后续新正文未知，不宣称已证明全程预算可行。实际后续请求仍必须按完整输入准入，超限即停止。
- 16 个保护路径与 467 份旧执行源码副本保持；旧报告、原始响应、评分和费用未修改。004 后累计 **732 请求／3,956,467 已知 tokens**，另列 **1,030,414** 历史未知占用。探针入口继承最新 receipt，不遗漏 004 的 13,179 tokens。

离线验收期间没有新增外部模型请求。私有证明位于 `artifacts/acceptance/writer-sections-20261024/`。旧非法 JSON 仍不可接受；章节拆分不能保证供应商总会返回合法 JSON，也不能保证新正文科学正确。真实质量目标仍需新的有界、同源码三域验收，旧终态不能复活，失败不得从分母删除或追加运行直到通过。
