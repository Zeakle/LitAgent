# Evaluation 指标与交付

工作台的「质量」页显示报告的评估结果、问题位置和交付状态。每次评估绑定当时的报告版本。改稿后的复评有自己的结果，可与初稿对照。

## 三个指标

| 指标 | 计算方式 | 何时可用 |
| --- | --- | --- |
| 引用 ID 有效性 `citation_accuracy` | 有效去重引用 ID 数 ÷ 去重引用 ID 数与格式错误项数之和 | 正文和证据账本可用。这个指标只检查引用 ID 和格式。 |
| 科学断言支持率 `faithfulness` | 获支持的科学断言数 ÷ 全部科学断言数 | 科学断言非空，清单有效且全部完成核验。 |
| 内部一致性 `internal_consistency` | max(0, 1 − 0.2 × 唯一矛盾对数) | 新运行比较同一对象、指标和条件下的科学断言。真实检查返回零对矛盾时为 1.0。仅检查问题覆盖的历史版本显示“不适用”。 |

默认配置使用 RAGAS 拆分并核验科学断言。LitAgent 为每个正文单元提供它实际引用的证据原文。全局请求只判断科学断言之间的矛盾，返回可定位的断言对。`evaluation_checks` 中的执行与清单状态说明核验是否完整、分数是否有效。

普通 Live 工作台为 RAGAS 的两步调用分别选择模型。Pro 根据报告原句拆出断言（`llm.evaluation_inventory_model`），Lite 根据该处实际引用的原文判断支持关系（`llm.evaluation_model`）。省略前一项时，两步都使用评估模型。写作前的论文证据提取另由 `llm.extraction_model` 控制。

严格交付要求引用 ID 全部有效、科学支持率为 **1.0**、矛盾对数为 **0**。Faithfulness 和内部一致性继续以 **0.8** 为基础评分阈值。历史结果保留运行时的检查范围。

## 阅读状态

| 状态 | 含义 |
| --- | --- |
| `passed` / `failed` | 指标或检查已有可用结论。 |
| `unverified` | 材料或步骤不完整，尚无可用结论。 |
| `error` | 评估执行或返回结果出错。 |
| `not_applicable` | 该检查不适用于这份报告。 |

不可用的分数显示为空。核验中断时，页面仍可显示已核验的断言数量。是否可交付以报告的交付状态为准。

## 审阅、复评和 Jev

Reviewer 在写作阶段提出编辑意见。Evaluation 在此之后检查断言、引用和整篇报告。若诊断允许修订，候选稿须完成复评才能进入交付。前置 Jev 默认检查提取候选的合法性与格式，终稿 Judge 已停用。
