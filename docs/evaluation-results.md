# Evaluation 指标与交付

工作台的「质量」页显示报告的评估结果、问题位置和交付状态。每次评估绑定当时的报告版本。改稿后的复评有自己的结果，可与初稿对照。

## 三个指标

| 指标 | 计算方式 | 何时可用 |
| --- | --- | --- |
| 引用 ID 有效性 `citation_accuracy` | 有效去重引用 ID 数 ÷ 去重引用 ID 数与格式错误项数之和 | 正文和证据账本可用。这个指标只检查引用 ID 和格式。 |
| 科学断言支持率 `faithfulness` | 获支持的科学断言数 ÷ 全部科学断言数 | 科学断言非空，清单有效且全部完成核验。 |
| 内部一致性 `internal_consistency` | max(0, 1 − 0.2 × 唯一矛盾对数) | 断言清单有效，矛盾检查完整返回。 |

默认配置使用 RAGAS 的 Faithfulness 断言分解和支持判断。LitAgent 为每个正文单元提供它实际引用的证据原文，并按整篇报告的断言数汇总。核心覆盖、章节分析、结构、方法披露和局限性另行检查，可在 `evaluation_checks` 查看结果。

指标的基础阈值是 **0.8**。完整核验后的分数可以达到该阈值，但严格交付仍要求科学支持率为 **1.0**、没有矛盾，且所有必需检查通过。

## 阅读状态

| 状态 | 含义 |
| --- | --- |
| `passed` / `failed` | 指标或检查已有可用结论。 |
| `unverified` | 材料或步骤不完整，尚无可用结论。 |
| `error` | 评估执行或返回结果出错。 |
| `not_applicable` | 该检查不适用于这份报告。 |

不可用的分数显示为空。核验中断时，页面仍可显示已核验的断言数量。是否可交付以报告的交付状态为准。

## 审阅、复评和 Jev

Reviewer 在写作阶段提出编辑意见。Evaluation 在此之后检查断言、引用和整篇报告。若诊断允许修订，候选稿须完成复评才能进入交付。前置 Jev 默认检查提取候选的合法性与格式，终稿 Judge 已停用。
