- **完整快照**：只有新计划将合法解析但超数量的章节隔离暂存，原响应及数量诊断全部保留。取得完整五章后再构造范围与预算；不以缺失章节的部分稿件预估完整复评，不在容量修复前生成摘要或交付报告。坏JSON或其他schema错误仍按原门禁拒绝，获批准的EOF政策仍须完整schema及语义字节保真。
- **共享额度**：初稿、摘要及后续修订共用最多两次。范围修复后只是`locally_valid_unverified`；完整Reviewer、Evaluation、科学支持1.0、核心覆盖和全局检查继续执行。模型拒绝、非法协议、未知用量、取消和重复提交不会自动追加请求；只有同一调用内已确认的可修本地质量问题可使用剩余一次。
- **异步保护**：发送前复制授权目标；响应后重新核对完整正文SHA及摘要依赖正文SHA。调用方不能在等待响应时更换版本或把目标移向其他段落。候选不通过时不提交。
