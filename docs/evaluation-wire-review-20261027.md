2026-10-27。本批为离线工程修复；单题上限保持 **1,000,000 tokens／64 请求**。不降低科学支持率 1.0、完整核验、核心覆盖或输出预留，不新增付费调用。

## 修复内容

新增显式 `host-citation-alias-list-v1`，仅在 `planned-budget-v3` 的原生支持核验批次启用。每条断言原先重复发送两次相同的来源别名，现在可发送有序别名列表。宿主先验证原文单元、片段、实际引用与材料身份；未知字段、引用重绑定、重复别名或越权引用明确拒绝。

后端 canonical 输入及核验逻辑保持原字段。完整原始支持文本、支持片段、条件、断言顺序、原文范围和原生输出 schema 均保留。版本进入计划和运行身份，旧 checkpoint 不能跨输入版本恢复；旧 v2 和 legacy 请求保持原编码。

预算预检、实际请求和拒绝诊断共用构造器。两种候选均包含完整提示、外层 JSON 编码及原生 schema；仅当新编码更小时才使用。否则发送逐字相同的旧编码。此选择不修复错误引用，也不授予科学支持。
