# 支持片段别名：完整来源与规范定位保留

2026-10-27，本批为离线工程修复。每题 **1,000,000 tokens／64 请求**硬上限保持，运行中不扩额；没有新增付费请求。

## 变更

`planned-budget-v3` 的支持核验批次使用版本化 `host-citation-support-aliases-v2`。模型在同一批次内使用 `p1` 等短键选择支持片段，宿主依据精确双射还原规范 ID。映射不发送给模型，完整原文、来源身份、支持范围和所有科学约束保留。

支持表键和原生输出 schema 的两处枚举一起变换。预检、实际发送和拒绝诊断使用同一构造器；只在计入提示、输入及原生 schema 后确实更小时采用，否则输入和 schema 一起回退原编码。旧 v2／legacy 编码不变。新输入版本进入预算和运行 fingerprint，不能跨版本恢复。

Evaluation 请求记录保留未还原的 `response.content`；已有 provider receipt 不作改写。本批未新增 Chat HTTP 原包捕获能力。Evaluation 先验证响应结构，再还原 `support_basis[].support_id` 和 `aspect_checks[].support_ids`，随后执行原有科学支持与归属检查。checkpoint 保存规范决策。未知、混合命名或错误枚举不猜测修正；失败响应仍结算已知 usage，不发额外请求。
