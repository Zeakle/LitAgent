- 预算按 `max(500000, ceil(1.1 × R / 10000) × 10000)` 计算；只有不超过 100 万 tokens／64 请求且上下文满足要求的计划才能创建账本。被拒绝计划中的计算额度不是已分配额度。
- 新账本使用显式阶段和请求身份保护后续额度，持久化发送前预留、发送标记、实际用量和未知占用；幂等结算、异步隔离、取消及重启不重发。激活时保留已经发生的准备费用；材料冻结前仍使用既有准备链路。
- 新服务端 profile 使用原 Responses API／原生 schema／EOF 政策／范围修复，Pro 关闭思考且不传 low effort，Reviewer 和 Evaluation 保持 Lite。旧 profile、旧 API 默认值和历史指纹保持。
- `RunOptions`／创建接口显式接受新预算策略；仅适用于严格 writer v2 且 Judge/Jev 关闭的运行。普通旧请求不自动改策略。预算计划进入身份，独立于引用样式。
- 工作台、同源 JSON／CSV／Markdown／HTML 展示准入结果；预留、实际用量和未知占用分别记录，不产生科学评分。诊断字符串有长度边界；完整原文引用不因诊断边界而被裁剪。
