源归档实际包含120条外部搜索记录及60条记忆召回记录，去重输入共180条，去重后132篇。此前方法披露只列搜索，漏列召回，造成表面矛盾。

新运行从实际 `recall_*` 输出记录召回数量，在中英文附录同时披露召回记录数与去重前发现记录数；论文数和证据条数仍分开。缺记录时不假定为0，旧记录不补造、不改写。
