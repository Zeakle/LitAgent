# Release verification

Check the [CI workflow runs](https://github.com/Zeakle/LitAgent/actions/workflows/ci.yml) for the status of a specific commit. The [release checklist](release.md) describes what is tested before a release.

The offline workbench ships with sample reports, evidence navigation and export. It can be run without a model service. Live Survey is experimental. Its results depend on the sources available for each question and the outcome of that run's evaluation.

The public records include the [retrieval comparison](../benchmarks/rag/RESULTS.md), a [report revision case](../src/litagent/static/presentation/frozen-repair-377-380.json), and [run 055](closeout.md), which stopped before Evaluation. Each record describes the conditions under which it was produced.
