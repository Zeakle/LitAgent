# 工作台使用指南

## 启动与准备

完成 [安装](../README.md#快速开始) 后，在终端运行：

```sh
litagent demo --presentation
```

打开 [工作台首页](http://127.0.0.1:8000/presentation)。此模式使用随项目提供的样例和公开运行记录，无需 API 密钥、Docker 或模型权重。首次安装依赖需要联网。

## 阅读报告和证据

1. 从首页进入「离线样例」。在「报告」页点击正文里的引用编号，查看对应论文和证据片段。
2. 打开「执行」，在阶段总览、任务 DAG 和调用时间轴之间切换。
3. 打开「质量」，查看引用 ID 有效性、科学断言支持率、内部一致性和交付状态。可展开的诊断会标出正文位置和对应证据。
4. 从报告页切换引用样式，或导出 Markdown、PDF、Word 和文献数据。学术引用样式需要 Node.js。预览中文 PDF 或 Word 需要相应的中文字体，例如 Noto CJK。

离线样例的正文和评分来自测试数据。查看真实运行时，任务结束、评估完成和通过交付是三个单独的状态。

## 查看实验记录

- **检索对比**：首页列出各配置的召回率、排序指标和延迟。数据集及测量条件见[检索实验](../benchmarks/rag/RESULTS.md)。
- **正文修订**：在首页打开「真实修订案例 377 → 380」，选择一条断言查看原句、改写和实际引用。案例使用同一份冻结证据，复评时重新抽取的 398 条断言全部获支持。[案例数据](../src/litagent/static/presentation/frozen-repair-377-380.json)
- **未完成的评估**：055 的第一题在 Reviewer 阶段中断。公开记录提供草稿、来源、停止原因和用量。[055 运行记录](closeout.md)

## 使用自己的研究问题

按[真实运行说明](../README.md#可选真实运行)配置模型服务并启动 Live 工作台。新建 Survey 后可在「执行」页跟踪进度。模型调用由服务商计费。任务分工和交付规则见[系统架构](system-overview.md)。
