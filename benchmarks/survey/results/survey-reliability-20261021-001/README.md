## 变更及其边界

现有 Worker 内拆为五章正文、随后摘要结论两次请求，共享原预算。每阶段保留完整来源、严格 schema、原响应 SHA、输入身份与不可自动重发 journal。旧 API 默认及 fingerprint 保持；3742 项离线测试通过只证明已覆盖工程契约。

此次正文阶段即失败，所以**没有发送摘要请求**。客户端未设置 stop 序列，也未裁剪返回 content；原响应不能通过 JSON 解析。减去摘要任务仍不足以解决此真实输入的协议稳定性，不能将原因简单归为输出上限或断言模型科学推理弱；更不能据 HTTP 200、finish stop 或 strict schema 判通过。

没有补括号、删约束、重跑到通过，也没有科学评分。新运行重新检索，不能与旧结果构成同材料严格配对实验。本轮没有新增消融或模型比较。

本次硬限制最多 3 观察、1,500,000 tokens／192 请求，每题 500,000／64。底层 18 槽位模板的 9M 总池不是本次使用额度；实际仅 1 题。历史 582 请求、3,097,921 已知 tokens 与 1,003,467 未知占用保留，新累计 609 请求、3,223,944 已知 tokens，未知占用未增加。
