# Survey Benchmark Live Pilot, 2026-08-25

## Scope

This is a sanitized summary of a cost-bounded live pilot. It ran one case from each
of the Few-shot, Vision Transformer, and NeRF domains against all three Survey
profiles. It is not the formal 39-run baseline: there were no repetitions, the
generation and Judge model were the same, and the accepted ground truth remains
`owner_approved_ai_assisted` rather than independently `human_reviewed`.

Source revision: `c49f549`. Generation and Judge model: `deepseek-v4-flash`, with
Judge thinking disabled. Private reports, evidence ledgers, RunArtifacts, and trace
identifiers remain under the ignored `artifacts/` boundary.

Citation precision is `null` for every profile because the generated reports did

The Judge reported faithfulness `1.0` for the eight substantive reports, meaning its
audited factual claims were supported by the run-scoped evidence ledger. This does
not offset topic coverage and citation recall: a report can faithfully summarize the
wrong or incomplete paper set.

## Acceptance Gaps

1. All three profile pairs were marked `non_comparable_external_inputs`; planner and
   external-search snapshots differed between sequential runs. Absolute metrics are
   retained, but no profile delta is causally attributable to RAG mode.
2. Required-paper citation recall was `0.0` in every run. Local RAG improved some
   upstream paper coverage, but that evidence did not survive into reviewed report
   citations.
3. Runtime RAGAS faithfulness was skipped in all nine runs: eight
   `IncompleteOutputException` results and one run without usable report evidence.
   Citation evaluation also produced two empty/invalid JSON responses.
4. Full-text runs showed repeated reviewer schema failures, extraction timeouts, and
   one empty synthesis. Selected full text has not demonstrated an end-to-end gain.
5. The pilot is self-judged and has only one sample per profile/case. It supports
   engineering diagnosis, not a statistically stable model-quality claim.

## Conclusion

The live pilot validates the benchmark's checkpointing, artifact integrity, trace
coverage, failure isolation, and cost accounting. It does not establish a winning
profile or a formal Survey quality baseline. The next paid run should happen only
after freezing external inputs, repairing runtime evaluator structured output, and
ensuring required RAG evidence reaches final citations.
